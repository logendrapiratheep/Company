AUREON Studio — Website Source Code

This is the latest six-service version of your website.

GET STARTED
1. Extract this ZIP.
2. Open index.html in your browser, or open the folder in VS Code and use Live Server.
No npm install, framework, or build step is required.

FILES TO EDIT
index.html: company text, services, portfolio links, and inquiry form options.
style.css: colors, fonts, layout, responsive rules, and animations. The final AUREON section contains the current redesign overrides.
script.js: scroll reveals, parallax, service selection, email draft, and copy inquiry behavior.
assets/: example SVG artwork and original cinematic hero image.

CONTACT
The form prepares an email to logendrapiratheep@gmail.com using the visitor's email application. It does not send messages automatically or store submissions.
To change the address, update both index.html and script.js.

GITHUB PAGES
Upload the CONTENTS of this extracted folder to the repository root, so index.html is directly at the top level. In Settings > Pages, select Deploy from a branch, main, /(root), and save. This is a static website; no Node.js build is needed.

NOTES
Google Fonts require internet access; fallback fonts are configured.
Service previews are illustrative concepts. Linked portfolio and FleetFlow sites are external projects.
The cinematic hero is an AI-generated artwork.
The source download has no ChatGPT sign-in requirement. Hosting access depends on where you deploy it.
